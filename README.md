# ООО «СтройМатериалы»

Настольное приложение для торговой организации, продающей строительные материалы.
Позволяет вести каталог товаров и заказы, разграничивая доступ по ролям сотрудников
и клиентов. Данные хранятся в локальной базе SQLite и наполняются из Excel-файлов,
которые предоставляет заказчик.

## О проекте

Приложение решает три задачи:

1. **Каталог товаров.** Показывает список из 30 позиций с фотографией, артикулом,
   производителем, категорией, ценой, скидкой, остатком на складе и описанием.
   Товары со скидкой больше 12 % автоматически выделяются оранжевым фоном карточки,
   чтобы менеджер сразу видел позиции с повышенной уценкой.
2. **Заказы.** Ведёт журнал заказов: номер, состав (артикулы и количество), даты
   оформления и доставки, пункт выдачи, ФИО клиента, код получения и статус
   («Новый» или «Завершен»).
3. **Разграничение доступа.** Один и тот же интерфейс показывает разный набор
   возможностей в зависимости от роли вошедшего пользователя — от простого просмотра
   каталога до полного редактирования товаров и заказов.

### Как устроено

Приложение открывается в собственном окне (не в браузере) с помощью библиотеки
**pywebview**: это обычное настольное окно, внутри которого отрисовывается
HTML-интерфейс. Такой подход даёт привычный внешний вид настольной программы и при
этом позволяет использовать гибкую вёрстку.

- **Серверная часть** написана на Python. За работу с базой отвечает **SQLAlchemy**,
  сами данные лежат в файле `data/materials.db` (SQLite). Структура таблиц описана
  отдельным SQL-файлом `app/db/schema.sql` — база создаётся именно по нему.
- **Интерфейс** написан на чистом JavaScript без внешних библиотек и без сборщика.
  Ничего не загружается из интернета, поэтому приложение полностью работает офлайн.
- **Связь между ними** идёт напрямую: JavaScript вызывает методы Python
  (`pywebview.api.*`), а Python возвращает готовые данные. Промежуточного
  веб-сервера с запросами по сети нет.
- **Пароли** не хранятся в открытом виде: при импорте они превращаются в хеш
  (библиотека Werkzeug), и при входе сравниваются именно хеши.
- **Права доступа** проверяются дважды — интерфейс не рисует недоступные кнопки,
  а Python дополнительно проверяет роль перед каждым изменением данных. Поэтому
  обойти ограничения через консоль разработчика невозможно.

### Возможности по ролям

| Роль | Просмотр товаров | Поиск, фильтр, сортировка | Редактирование товаров | Просмотр заказов | Редактирование заказов |
|---|:---:|:---:|:---:|:---:|:---:|
| Гость | да | нет | нет | нет | нет |
| Авторизированный клиент | да | нет | нет | нет | нет |
| Менеджер | да | да | нет | да | нет |
| Администратор | да | да | да | да | да |

**Гость** — вход не требуется, достаточно нажать ссылку «Просмотр товаров как гость»
на экране входа.

**Поиск** ищет сразу по названию, артикулу, категории, описанию и производителю,
причём по нескольким словам одновременно. **Сортировка** доступна по цене, скидке и
остатку — по возрастанию и убыванию. **Фильтр** отбирает товары одного производителя.

**Редактирование** — это добавление, изменение и удаление записей. Для товара можно
загрузить фотографию с компьютера, для заказа — указать состав в формате
«артикул, количество, артикул, количество».

## Установка

Требуется Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Наполнение базы данных

```bash
python data/import_excel_to_db.py
```

Команда создаёт файл `data/materials.db` по схеме `app/db/schema.sql` и заполняет его
данными из папки `data/import/`:

| Файл | Что содержит | Записей |
|---|---|---|
| `products_import.xlsx` | Товары каталога | 30 |
| `users_import.xlsx` | Сотрудники и клиенты | 10 |
| `orders_import.xlsx` | Заказы | 10 |
| `pickup_points_import.xlsx` | Адреса пунктов выдачи | 36 |

Запускать заново нужно после любого изменения Excel-файлов. Команда каждый раз
пересоздаёт базу с нуля, поэтому внесённые в приложении правки будут потеряны.

Изображения в импорте не участвуют: фотографии товаров, логотип и иконка уже лежат
в `app/static/img/`, а таблица товаров лишь указывает имя файла с фотографией.

## Запуск приложения

```bash
python app/main.py
```

## Application Notes

Замечания, которые стоит учитывать при работе с приложением.

- **Данные пересоздаются при импорте.** `data/import_excel_to_db.py` удаляет базу и
  создаёт её заново. Если вы добавляли товары или заказы через интерфейс, перед
  повторным импортом сохраните копию `data/materials.db`.
- **База не хранится в репозитории.** Файл `data/materials.db` указан в `.gitignore`,
  поэтому после клонирования проекта импорт нужно выполнить обязательно. Без него
  окно откроется, но при загрузке каталога появится ошибка `no such table: products`.
- **Пароли восстановить нельзя.** В базе лежат только хеши. Исходные пароли есть
  лишь в `users_import.xlsx`.
- **Статические файлы отдаются локальным HTTP-сервером.** Интерфейс загружается не
  напрямую с диска, а через служебный сервер на `127.0.0.1` со случайным портом.
  Это обходит ограничение WebKit на macOS, из-за которого стили и скрипты,
  загруженные по пути `file://`, блокируются. Наружу порт не открывается.
- **Инструменты разработчика доступны, но не открываются сами.** Нажатие правой
  кнопкой по окну даёт пункт «Inspect Element» — он полезен при отладке вёрстки.
- **Фотографии товаров хранятся в файлах.** Загруженное через интерфейс изображение
  сохраняется в `app/static/img/products/` под именем вида `АРТИКУЛ_случайныйкод`
  с расширением исходного файла. При удалении товара его фотография остаётся на диске.
- **Скидка выше 12 % — правило оформления.** Порог задан в `app/static/js/main.js`,
  а сам цвет подсветки `#F4A460` — в переменной `--discount-highlight` в
  `app/static/css/main.css`.
- **Изменение названия организации.** Название задано один раз в
  `app/static/js/app_config.js` и оттуда попадает и в шапку, и в заголовок окна.
- **Требования к системе.** Приложению нужен установленный системный компонент для
  отображения веб-содержимого: на Windows — WebView2, на macOS — встроенный WebKit,
  на Linux — WebKitGTK.
